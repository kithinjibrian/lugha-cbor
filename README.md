# lugha-cbor

[CBOR](https://www.rfc-editor.org/rfc/rfc8949) for [Lugha](https://github.com/kithinjibrian/lugha), in pure Lugha. The decoder is safe on untrusted input: every claimed length is checked, and depth and size are limited.
